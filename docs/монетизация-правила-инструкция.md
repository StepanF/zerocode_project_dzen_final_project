# Монетизация и правила

## Правила Дзена для авторов: за что можно потерять канал
Нет. Дзен проверяет уникальность и банит за плагиат. Канал может быть заблокирован навсегда. Пишите только оригинальный контент или рерайт с полной переработкой смысла.

Запрещены: насилие, экстремизм, порнография, продажа запрещённых веществ, обман читателей. Полный список, в правилах Дзена. За нарушение, блокировка канала без предупреждения.
