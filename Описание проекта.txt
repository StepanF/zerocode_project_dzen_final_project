Название
«Автогенератор статей для Дзена»

Проблема
Большие трудозатраты на создание контента при ведении канала: нужно найти тему, которая была бы интересна читателям, написать 4-5 тысяч знаков живым русским языком учитывая паттерны, инфостиль, проверить юридическую и площадочную легальность, придумать и сгенерировать картинки.

Пользователь
Данный проект создан для личного пользования, под определенный канал
Полезен любому блогеру, копирайтеру, ведущему канал на Дзене после настойки тематики


Основная функция
Вход: команда «напиши статью» 
- Шаги:
  a. Суб-агент dzen-topic-researcher ищет трендовые темы на зарубежных сайтах, ведёт журнал тем в памяти (резерв, чёрный список повторов), возвращает 7 вариантов с hook-ами.
     Пока происходит поиск новых тем, чтобы автор не скучал - предлагается список тем из предыдущих найденных вариантов 
  b. Автор выбирает тему или несколько тем; собирается исследовательский бриф (тезис, аудитория, структура виральности, ключевые факты).
  c. Суб-агент dzen-topic-researcher/основная сессия перечитывают источники — только полный текст, сводки помечаются.
  d. Пишется статья на русском по базе знаний docs (инфостиль, виральность, правила Дзена) и скиллу.
  e. Контроль качества: грамматика, юридический фильтр (РФ), анти-AI проход по 38 паттернам склопа, честность фактов (пересказы помечаются), дополнительный анти робот проход (начало/финалы не повторяются между статьями), правила Дзена на картинки; скрипт check_article.py сверяет объём и шаблон имени файла.
  f. Запускается генерация картинок: используется локальный ComfyUI (модель RealVisXL V5), по 5 seed-вариантов на обложку и каждую иллюстрацию; обложки кропаются до 1080×608.
Выход: папка статьи с .md (статья с YAML-фронтматтером + служебный раздел: источники, промпты картинок, параметры генерации) и комплектом PNG картинок.

Формат результата
Готовая к публикации статья в Markdown + 20 картинок с вариантами на выбор (обложка 1080×608, иллюстрации 1344×768). От автора остаётся только выбрать варианты картинок и вставить текст в Дзен-студию.

Минимальный функционал (MVP — уже реализовано)
- Конвейер «команда → темы → бриф → статья → QC → картинки» (этапы 1–5 скилла), отработан на 16 статьях.
- Журнал тем суб-агента:  резерв кандидатов и защита от повторов.
- Контроль правил сохранения: шаблон имени, лимиты Windows, папка на статью.
- Генерация картинок с 5 вариантами на сюжет для обложки и внутренных картинок.
- Версионирование репозитория (Git/GitHub).

+ Функционал(toDo)
- дообучение стиля под личный «голос»(реализован частично, но есть над чем поработать);
- автоматическая переделка формата итоговой статьи после одобрения;
- подбор более качественной локальной модели для генерации картинок или переход на mcp;
- добавление единой стилистики промптов картинок;
- обратная связь по аналитике (CTR, дочитывания) в выбор тем;
- масштабирование проекта, возможность быстрой настройки хоть под 100 каналов.

Технологии
- Оркестрация: Claude Code — маркдаун-скиллы (.claude/skills/dzen-viral-writer), суб-агент (.claude/agents/dzen-topic-researcher.md), память агента (.claude/agent-memory/), правила проекта.
- Поиск фактов: веб-поиск, WebFetch/curl, разбор HTML текстов скриптом на Python.
- Генерация картинок: ComfyUI 0.43 локально (SDXL-модель RealVisXL_V5.0_fp16), HTTP API , Python + PIL для кропа обложек; воркфлоу — JSON.
- Контроль качества: Python-скрипт check_article.py (объём тела в знаках и словах, проверка имени по шаблону, лимиты Windows) + ручные проходы по справочнику паттернов AI-слопа и таблицам канцелярита.
- Форматы: Markdown, PNG, JSON (воркфлоу ComfyUI, журнал тем).
- Версионирование: Git, GitHub
