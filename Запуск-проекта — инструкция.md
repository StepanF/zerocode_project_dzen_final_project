# Инструкция по запуску проекта «Дзен-автогенератор статей»

Проект: конвейер, который превращает зарубежные тренды в готовые статьи для Дзен-канала «Логика вещей».
Дата записи: 2026-11-15.

## 1. Что должно быть установлено (предпроверка)

- **Windows 11** (проверено на этой конфигурации), терминал.
- **Claude Code** — установлен и привязан к вашему аккаунту.
- **Git** — установлен, репозиторий `<адрес репозитория>` подключён как remote `origin`.
- **Python 3.12** — системный, (нужен для скриптов проверки и разборки HTML).
- **ComfyUI (локальный, офлайн-генератор картинок)** — разложен в `C:\ComfyUI\App`: запускной питон `python_embeded`, сам сервер в подпапке `ComfyUI`. Модель `RealVisXL_V5.0_fp16.safetensors` должна присутствовать в списке чекпойнтов.
- **Сеть** — работающие веб-поиск/WebFetch (источники фактов подтягиваются из зарубежных сайтов).

Проверка ComfyUI без запуска: в браузере или `curl` открыть `http://127.0.0.1:8188/system_stats` — если ответ пустой, сервер спит.

## 2. Старт сессии

1. Открыть терминал **в папке проекта**: `C:\....\zerocode_project_dzen\`.
2. Запустить `claude`.
3. Правила подхватятся сами:  из `zerocode_project_dzen\CLAUDE.md` (правила Дзен-проекта). Дополнительно будут загружены скиллы и агенты из `.claude\`.

Ничего руками настраивать не нужно — главное запускаться именно из папки проекта, а не из родительской.

## 3. Главный сценарий: написать статью

1. **Команда в чат:** «напиши статью» (без темы) или «напиши статью на тему X».
   - Команда без темы всегда сначала запускает суб-агента `dzen-topic-researcher`: он ищет тренды на зарубежных сайтах и показывает свежую волну тем + резерв прошлых поисков (нумерованные списки).
   - Команда с темой суб-агента тем не запускает: тема сразу уходит в бриф и статью (решение Хозяина, 2026-11-15).
2. **Выбор темы:** ответить номером из списка, например «15» или «68а». Писать статью без вашего выбора проект не станет — это защита от «навязанных» тем.
3. Дальше конвейер сам проходит этапы (по скиллу `dzen-viral-writer`):
   - чтение источников целиком (не по сводкам! сводки помечаются в служебном разделе),
   - исследование бриф — тезис, аудитория, hook, структура,
   - статья на русском, тело 4000–6000 знаков, чтение 3–4 минуты,
   - контроль качества (грамматика, юридический фильтр РФ, 38 паттернов ИИ-слопа, инфостиль, «не робот»-проход, честность фактов),
   - сохранение в `дзэн статьи\NN — Название — дата — (дата)\` + генерация картинок,
   - обложка и по 3 иллюстрации в 5 вариантах каждой из них.
4. **Ваш выбор картинок:** открыть папку статьи, посмотреть `обложка-вариант-1…5.png` и `иллюстрация-N-вариант-1…5.png`, выбрать нужные номера в чате. Служебный раздел в конце `.md` для читателя скрыт — это внутренняя записка (там ссылки и промпты).

Если ComfyUI ещё не запущен — его поднимет Claude Code сам следующей командой (см. раздел 5).

## 4. Дополнительные команды в чате

- «покажи резерв тем» — вывести список кандидатов из журнала суб-агента (`.claude\agent-memory\dzen-topic-researcher\dzen-topic-search-log.md`).
- «запусти суб-агента тем» — форс-запуск свежего поиска тем (сами темы суб-агент ищет на каждой «напиши статью» без темы; при команде с темой ищется только этой командой).
- «проверь статью <путь>» — прогнать `check_article.py` и показать объём/правильность имени файла.
- «закоммитим» — предложение автором коммита и пуша; само по себе Git ничего не коммитит, ждёт явного «да».
- «опиши проект» — краткая сводка проекта по точкам: название/проблема/функция/технологии.

## 5. Запуск ComfyUI вручную

Каноническая команда (из скилла), исполнение в фоне:

```
cd C:/ComfyUI/App
./python_embeded/python.exe -s ComfyUI/main.py --port 8188 > ComfyUI/user/comfyui_session.log 2>&1
```

Важно: вывод обязан уходить в файл (`> ... 2>&1`). Если запустить через передачу в `| head` или другой пайп, прогресс-бар падает с ошибкой и генерации ломаются. Не использовать comfy-cli для запуска — он тянет системный Python, в котором нет нужных пакетов.

Проверка готовности: `curl http://127.0.0.1:8188/system_stats` — появился JSON, значит сервер поднялся (нормальное ожидание: первые 30–60 секунд).

## 6. Контроль качества статьи (если нужно руками)

```
cd C:\...\zerocode_project_dzen
python ".claude\skills\dzen-viral-writer\scripts\check_article.py" "дзэн статьи\<имя папки>\<имя файла>.md"
```

Скрипт печатает: объём тела в знаках и словах (норма 4000–6000), сверку с `length:` во фронтматтере, длину пути (лимит 260 символов) и результаты проверки имени файла под Windows.

## 7. Публикация в Дзен (вручную, вне проекта)

1. Открыть `dzen.ru/editor`, войти через Яндекс ID, «Создать публикацию» → «Статья».
2. Заголовок ≤ 56 символов, с главным ключевым словом.
3. Обложка 1080×608 px (готовая лежит в папке статьи).
4. Текст перенести из `.md`; изображения вставить по 1 на каждые 3–4 абзаца; служебный раздел НЕ копировать.
5. Описание ≤ 160 символов — заполняется для поиска Яндекса.
6. «Опубликовать» — модерация 10–30 минут.

## 8. Версионирование

- Периодически (обычно в конце рабочего блока) предлагаем коммит: `git add -A; git commit -m "<что сделано>"; git push origin master`.
- Папка `toDo\` в репозиторий не ходит (исключена `.gitignore`) — там отложенные скиллы.
- `.playwright-mcp\`, `.tmp\` — временные, в репозиторий не коммитить.

## 9. Что нельзя трогать без явного разрешения Автора

- Скиллы и суб-агенты в `.claude\skills\` и `.claude\agents\` — правки только после того, как Автор увидит точный текст изменений и ответит «да».
- Структуру папок проекта (архитектура меняется только с объяснением).
- Файлы без прямого запроса — ничего не удалять.

## 10. Типичные проблемы и решения

| Проблема | Решение |
|---|---|
| WebFetch отдаёт «Unable to verify if domain is safe» | Обход через `curl -sL -A "Mozilla/5.0" <url> -o файл` + разбор HTML маленьким скриптом Python |
| Веб-страница отдаёт капчу/оболочку JS | Заменить источник: тот же материал на другом домене или пересказ поисковой сводки (но тогда пометить в служебном разделе!) |
| ComfyUI не отвечает на 8188 | Запустить по команде из раздела 5; если порт занят — найти процесс и перезапустить отдельно |
| Имя файла статьи не прошло проверку | Заменить недопустимые символы `< > : " / \ | ? *`, имя папки = имя файла без расширения |
| Кириллические пути ломаются в скрипте | Запускать питон с флагом `PYTHONUTF8=1` (для `python_embeded` — обязательно) |
| Claude Code «забыл» скиллы | Проверять, что сессия запущена из папки проекта, а из корневого README ничего не редактировано вручную |
