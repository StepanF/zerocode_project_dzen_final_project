# Справочник: Правила сохранения статьи

**Каждая статья живёт в своей папке.** Структура:

```
дзэн статьи/[Название статьи]/            ← папка, имя совпадает с именем файла статьи (без расширения)
├── [То же название].md                   ← сама статья
├── обложка-вариант-1.png … 5.png         ← сгенерированные обложки (кроп 1080×608)
└── иллюстрация-1-вариант-1.png … и т.д.  ← встроенные иллюстрации
```

Имя папки = имя файла статьи (формат ниже), без расширения `.md`.

Сохраняй статью по формату:
`[Номер] — [Название статьи на русском] — [Дата и время создания] — [Дата и время апдейта].md`

**Служебный раздел (обязателен в конце каждого файла статьи):**
В конце файла статьи добавляй раздел `**Служебный раздел (не публиковать)**` — это единственное место, где живут ссылки и упоминания:
- Источники фактов (с названиями и, по возможности, URL).
- Перелинковка: свои статьи, с которыми связана тема (без ссылок в тексте).
- Заметки о проверках (объём, ниша, источники).
- Промпты картинок по меткам `[IMAGE PROMPT (COVER)/(INLINE N)]` + негативный промпт + параметры генерации (модель, размер, семплер, seeds).

**Ограничения Windows для имён файлов (обязательно учитывать):**
- **Запрещённые символы:** `<` `>` `:` `"` `/` `\` `|` `?` `*` — их в имени быть не должно. При оформлении названия статьи внутри файла их использовать можно; в имя файла они не попадают. Вместо «:» в имени ставится «—» или пробел.
- **Запрещённые имена:** `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9` — вне зависимости от расширения.
- **Конец имени:** имя файла не может заканчиваться точкой или пробелом.
- **Длина:** имя файла — до ~255 символов; полный путь (папка + имя + расширение) — до 260 символов. Проверяй длину пути ДО сохранения; при превышении сокращай название статьи в имени папки и файла — и никакие настройки Git или ОС вместо этого не включать. Статьи имеют длинные названия, поэтому держи часть с названием статьи до ~60–80 символов, чтобы запас по длине всегда оставался.
- **Кириллица в имени:** допустима и не является ошибкой.
