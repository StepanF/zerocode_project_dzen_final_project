# Справочник Этапа 4 — Контроль качества и легальность

Читать и выполнить целиком перед сохранением статьи. Порядок сохранён из исходного скилла.

1. **Грамматика:** Безупречный русский язык, отсутствие опечаток.
2. **Юридический фильтр (РФ):** Полное соответствие законодательству РФ. Удалить любые призывы к запрещенной деятельности или упоминания запрещенных организаций.
3. **Сверка с `/docs`:** Проверка соблюдения всех требований проекта на 100% (docs — справочник; конфликт решается по CLAUDE.md, скилл сильнее).
4. **Анти-AI штампы (расширенный проход):**
   - Затирать запрещённые штампы: перформативная честность («честно скажу», «честная оговорка»), тизеры («а теперь самое интересное»), вводные-паразиты («разумеется», «на самом деле», «по сути»), хвосты «не X, а Y» (более двух на статью), оценки без факта, размытые числа.
   - Латинские вкрапления в русском тексте — искать и вычищать (в промптах картинок латиница допустима).
5. **Честность фактов:** препринты помечаются «рецензия не пройдена»; цифры из пересказов помечаются в служебном разделе; заявления компаний — «слова компании»; непроверяемое — не пишется.
6. **Правила Дзена на картинки (официальные):** обложка обязательна и соответствует теме (не кликбейт — иначе показ только подписчикам); запрещённые изображения на карточке (шокирующее/отвратительное, насекомые в еде, туши, тюремный быт) = вне ленты рекомендаций; в файле статьи обложка — первая картинка; интрига честная, обманывать нельзя.
7. **«Не робот»-проход:** уникальная структура (порядок секций и тип зачина не повторяют прошлые статьи канала), нет дословных фраз-наследий (см. правило «каждая статья — свои формулировки»), подпись и финальный вопрос — новые, первые предложения абзацев складываются в историю.
   Расшифровка правила «каждая статья — свои формулировки»: содержательные формулировки — вступления, финальные вопросы, «раздражители», подписи — пишутся каждый раз с нуля. Конкретную фразу из прошлой статьи (авторскую или сделанную по шаблону) можно перенести в новую только по прямому разрешению автора именно этой фразы — без такого разрешения повтор считается имитацией. Постоянные элементы канала (рубрика, форма приветствия, повторяющийся формат) допустимы и шаблоном не считаются: узнаваемый каркас работает на канал, если внутри него каждый раз новый текст. Источник правила: имитация строки «Мало что злит так же метко» (статья про лифт) в статье 06; смягчено Хозяином 2026-11-14 (вариант B+C); полная запись — в памяти Claude Code, файл no-imitated-signature-phrase.md.
7а. **Финальный тест «звучит как человек»:** после всех проходов прочитать весь текст вслух или вполголоса. Любое предложение, которое живой человек не сказал бы за столом, переписать простыми словами. Вычищать: шаблонные «мостики» («возникает законный вопрос», «цифры звучат грозно»), метафоры, растянутые дальше одного образа и неточные по смыслу, рубленые предложения без подлежащего («телеграфный стиль»). Тест идёт последним перед сохранением и замером объёма — он не отменяет остальные правила, а проверяет их результат.
7б. **Маркерный проход по AI-слопу:** работать по справочнику `references/ai-slop-patterns.md` (38 паттернов с примерами до/после) в три уровня: (1) артефакты копипаста из чат-ботов и «жёсткие запреты» паттернов 13 и 23 — найдено хоть что-то = править сразу; (2) кластеры: признак из групп «канцелярит», «AI-словарь», «правило трёх», «финал-афоризм», «резюмирующие заключения», «фальшивая доверительность», «рубленый драматизм» — 3–4 разных признака в одном абзаце = переписать абзац; (3) плотность: (маркеры/число слов)×100 — выше 1,5 = второй проход по всему тексту. Длинное тире (—) в русском тексте НЕ запрещать: это нормальная типографика РФ, ограничения на тире из английских списков ИИ-маркеров на наш язык не переносятся.
8. **Канцелярит-проход:** проверить текст по таблице замен:
   *проводить работу → работать · осуществлять контроль → контролировать · оказывать помощь → помогать · принимать участие → участвовать · является эффективным → работает/эффективен · представляет собой → это · выступает в роли → работает как · было принято решение → решили · для того чтобы → чтобы · в связи с тем, что → из-за того/из-за · в случае если → если · данный (= этот) → этот · осуществлять → делать · в рамках (не буквально) → удалить или упростить · на данный момент → сейчас · в целях X → чтобы X*
9. **Инфостиль — четыре приёма** (полный словарь — `docs/infostyle.md`, справочник):
   - **Оценку меняй на факт, сценарий или историю.** Не «отличные результаты», а конкретные цифры «89 из 100, на 6 выше прошлого»; не «удобный», а сценарий, в котором удобство видно. Вывод читателя прочнее прилагательного.
   - **Одна новая мысль на предложение.** Перегруз ловится не длиной, а числом новых сущностей: одна — норма на предложение, до трёх — для сложных тем. Лечится: удалить сущность; обобщить перед перечнем; объяснить по цепочке от знакомого к новому.
   - **Всё абстрактное — после конкретного.** Абстрактное обобщение работает после конкретики, а не вместо неё; разложи обобщение на осязаемые примеры.
   - **Цифра — в мире читателя.** Любому числу нужна привязка (прошлый замер, порог, сравнение); большие точные числа округляй до полезного уровня; проверь, что из соседства двух чисел не напрашивается ложный вывод.
10. **Отчёт автору:** после проверки показать список «что вычищено на ЭТАП 4» (или «чисто», если так) — правки не скрывать.
